# Sound credits

Every sound in brew is **synthesised at runtime** with the Web Audio API in `design/audio.js` (oscillators, filtered
noise, envelopes). There are no recorded samples, loops or music files, so there is nothing third-party to credit or
license. The voices were first written for the retired 3D lobby prototype (`git show 76fb830:lobby/js/audio.js`) and
ported and extended here (station sounds, pen scratch, stamp, warning blip, sparks, room tones, the generative lo-fi
bed).

If recorded audio is ever added, use CC0 sources only and list each file here: name, author, source URL, licence.
