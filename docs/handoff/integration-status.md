## Set up on a new laptop
```bash
git clone <repo> && cd Brew && uv sync
brew install libomp                      # macOS only: LightGBM needs it (Linux CI doesn't)
uv run playwright install chromium       # frontend tests
uv run pytest -q -m "not frontend"       # backend suite (~5 min, ~330 tests)
uv run pytest -m frontend                # client layer, rendering, e2e (Chromium)
uv run brew-api                          # → http://localhost:8000/  (FastAPI serves design/ at /)
```
Useful dev URLs:
- `http://localhost:8000/?clock=open` opens a world that starts at 07:00 instead of the wall clock.
- Add `&world=<id>` to attach to an existing world.
- `/design/brew.html?source=replay&fixture=morning_rush&speed=60` replays a fixture. Serve the repo root with
  `python3 -m http.server`.
- Without a backend, the page falls back to `design/data/demo-stream.jsonl` and the HUD dot shows "offline demo".
- For a fast café use `BREW_DB_ENABLED=0 BREW_LIVE_RATE=60 uv run brew-api`. To jump in time, use `POST /worlds/{id}/control`
  with `pause`, then `step {step_s}`, then `play`.
